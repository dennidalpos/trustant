# End-to-End Tests

End-to-end tests live under `tests/` and are opt-in. They are not part of
`go test ./...` because they interact with a live Trustant/Nuvolaris cluster,
launch apps and drive a browser.

> **Removed runtime.** Trustant no longer launches OpenCode (hard cutover to
> TruACP/Pi, see [pi.md](pi.md) and [4-launch.md](4-launch.md)). The OpenCode
> scenarios were deleted on 2026-11-25 (owner decision, task #29): the Issue 98
> prompt, action-workflow, compaction and authentication tests
> (`tests/e2e_issue98.sh`, `e2e_action_workflow.sh`, `e2e_compaction.sh`,
> `e2e_auth.sh`, `issue98.spec.mjs`, `issue98-session-tree.mjs`), the
> multi-provider benchmarks built on them (`e2e_provider_common.sh`,
> `e2e_private_app.sh`, `e2e_ollama_cloud_app.sh`, `e2e_regolo_app.sh`), the
> Issue 99 MongoDB capability scenario that ran through the same spec, and their
> diagrams. The previous text, scripts and diagrams stay in Git history.

There is currently no cluster E2E runner for TruACP/Pi. Provider benchmarks
and prompt-driven application checks return only with a new runner written for
that runtime. The runnable checks today are the Go suite and the Node tests
listed in `package.json`; the Playwright specs left under `tests/`
(`uix02`, `import-suggestions`, `inventory-terminal`) use
`tests/playwright.config.mjs`.

Generated benchmark reports, traces, and logs belong under `benchmark-results/`
and are local artifacts. They must be ignored by git and not committed.
