# Load the project context

1. Load the slim startup context with the SecondBrain MCP tool get_startup_context or scripts/knowledge.ps1 -Startup from the SecondBrain checkout.
2. Read the repository instructions (AGENTS.md) and follow their checks.
3. Ask before any commit, push or publication; record the outcome where the project tracks its work.
